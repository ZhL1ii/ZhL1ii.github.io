# ZhL1ii's Blog

A personal notes repository built with Astro-Paper. Site: `https://Zhl1ii.github.io`

## Tips for writing a post

Create a `.md` or `.mdx` file in `src/content/posts/`:

```yaml
---
title: "Post title"
pubDatetime: 2026-09-02T00:00:00+08:00
description: "A short summary of the post."
tags:
  - notes
draft: false
---
```

`title`, `pubDatetime`, and `description` are required. Use `draft: true` to hide a post from the published site.
