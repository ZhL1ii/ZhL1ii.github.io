给定一个整数数组：

```
[-2, 1, -3, 4, -1, 2, 1, -5, 4]
```

要求找到一个**连续子数组**，使它的元素和最大。

例如例中元素和最大的子数组为：

```
[4, -1, 2, 1]
```

和为`6`因此答案是`6`

这一题有多种解法：

## 前缀和

### 前缀和技巧

由于一个区间 `[left, right]` 的和可以用区间 `[0, right]` 的和减去区间 `[0, left-1]` 的和。这就是前缀和的思想。

所以可以定义`prefix[i]`，表示：

```
nums[0] + nums[1] + ... + nums[i-1]
```

注意，这里通常令：

```
prefix[0] = 0
```

例如：

```
nums:
[-2, 1, -3, 4, -1]

prefix:
[0, -2, -1, -4, 0, -1]
```

于是区间：`[left, right]`的和就可以直接得到：`prefix[right+1] - prefix[left]`

例如：`nums[1:4] = [1, -3, 4]`

那么：`prefix[4] - prefix[1] = 0 - (-2) = 2`

这样先遍历一次数组得出前缀和数组，之后在计算区间求和的时候就不需要再通过**遍历区间**来逐个求和了。所以最简单的代码可以这样写：

```go
func maxSubArray(nums []int) int {
	prefix := []int{0}

	sum := 0
	for _, num := range nums {
		sum += num
		prefix = append(prefix, sum)
	}

	res := nums[0]

	for left := 0; left < len(nums); left++ {
		for right := left; right < len(nums); right++ {
			res = max(
				res,
				prefix[right+1]-prefix[left],
			)
		}
	}

	return res
}
```

这段代码的时间复杂度为 O(n²)，相比枚举区间 + 遍历区间求和的最暴力的方法已经好了一些，但是还能进行优化。

### 利用本题的特性

已知：对于某一个固定的右端点 `right` 的区间和是：`prefix[right+1] - prefix[left]`

那么现在 `prefix[right+1]` 已经固定了，如果要想让整个表达式：
`prefix[right+1] - prefix[left]` 尽可能大，那实际上就是：**让 `prefix[left]` 尽可能小**。所以对于每个 `right`，我们根本不需要枚举所有 `left`。我们只需要知道 `right` 左边出现过的**最小 `prefix` 是多少**就能解决问题了

定义：`minPrefix` 表示当前已经见过的最小前缀和。那么：`prefix[i] - minPrefix` 就表示以当前这个位置作为右边界时，能够得到的最大子数组和。

举例：

还是：

```
nums =
[-2, 1, -3, 4, -1, 2, 1, -5, 4]
```

前缀和：

```
prefix =
[0, -2, -1, -4, 0, -1, 1, 2, -3, 1]
```

假设现在走到了`prefix[7] = 2`，我们要让`2 - prefix[left]`最大。前面最小前缀 `prefix[3] = -4`

所以：`2 - (-4) = 6`，对应区间`[4, -1, 2, 1]`，答案正好是 6。于是两层循环就又消掉了一层。

那么代码就可以简化为：

```go
func maxSubArray(nums []int) int {
	res := nums[0]

	prefix := []int{0}
	sum := 0

	for _, num := range nums {
		sum += num
		prefix = append(prefix, sum)
	}

	minPrefix := prefix[0]

	for i := 1; i < len(prefix); i++ {
		res = max(res, prefix[i]-minPrefix)

		minPrefix = min(minPrefix, prefix[i])
	}

	return res
}
```

像这样，算法的时间复杂度又进一步下降，仅剩下了两个次数为 n 的循环，时间复杂度降低到了O(2n) = O(n)，但还可以继续优化。

### 优化前缀和求算

观察上面的代码，我们提前将所有位置的前缀和求解了出来，放在了一个数组中。但是在后续的步骤中，我们其实**并不是随时都需要所有的前缀和**的。

在 `right` 不断向右移动的过程中，其实我们只关心下标 `right` **当前的前缀和**与当前记录的**最小前缀和**。而 `right` 又是按部就班地一格一格向右移动的，那我们大可不必将所有的前缀和提前求出。而是在 `right` 移动的过程中一边计算当前的前缀和 `prefix` 并记录当前已知的最小前缀和 `minPrefix`。

所以最后可以优化出这样一个版本：

```go
func maxSubArray(nums []int) int {
	res := nums[0]

	prefix := 0
	minPrefix := 0

	for _, num := range nums {
		prefix += num

		res = max(res, prefix-minPrefix)

		minPrefix = min(minPrefix, prefix)
	}

	return res
}
```

现在代码中的循环又减少了，时间复杂度是 O(n)，空间复杂度是 O(1)。

## 动态规划

前面的思路一直是：区间和 = 前缀和之差

现在我们不再考虑：left、right、prefix

上面的前缀和方法，本质上是让子数组以 `right` 结尾，求此时的最大和，现在以一个类似的角度思考问题：如果我必须让子数组以 `nums[i]` 结尾，那么最大和是多少？这就是进入动态规划的关键。

### 定义状态

定义：`dp[i]`，表示：**以 `nums[i]` 结尾的最大子数组和。**这里的“以 `nums[i]` 结尾”非常重要。

例如：

```
nums = [-2, 1, -3, 4]
```

如果：i = 3

那么所有候选结果为：

```
[4]
[-3, 4]
[1, -3, 4]
[-2, 1, -3, 4]
```

因为它们全部以 `4` 结尾。

### 如何得到 dp[i]

现在假设我们已经知道了 `dp[i-1]`，这表示以 `nums[i-1]` 结尾的最大子数组和。

那么当 `i` 向后移动时，即计算到 `nums[i]` 时，对应的子数组只有两种选择：

- 继续接上前面的子数组，则 `dp[i] = dp[i-1] + nums[i]`
- 不接上前面的子数组，则 `dp[i] = nums[i]`

那根据题目是求最大的子数组和，那计算 `dp[i]` 时，只需要取 `dp[i-1] + nums[i]` 和 `nums[i]` 之间的最大值即可。

亦即：$dp[i] = max(nums[i], dp[i-1] + nums[i])$

这就是所谓的**状态转移方程**。

### 举例

数组：

```
[-2, 1, -3, 4, -1, 2, 1]
```

首先：`dp[0] = -2`

然后：

```
nums[1] = 1

dp[1]
= max(1, -2 + 1)
= 1
```

说明：`-2` 是累赘。将其抛弃，从 [1] 重新开始。

继续：

```
nums[2] = -3

dp[2] = max(-3, 1-3) = -2
```

继续：

```
nums[3] = 4

dp[3] = max(4, -2+4) = 4
```

同理，重新从 4 开始。

之后：

```
dp[4] = max(-1, 4-1) = 3
dp[5] = max(2, 3+2) = 5
dp[6] = max(1, 5+1) = 6
```

所以：

```
dp = [-2, 1, -2, 4, 3, 5, 6]
```

最大值为 `6` 就是答案。

### 标准 DP 代码实现

```go
func maxSubArray(nums []int) int {
	dp := make([]int, len(nums))

	dp[0] = nums[0]
	res := dp[0]

	for i := 1; i < len(nums); i++ {
		dp[i] = max(
			nums[i],
			dp[i-1]+nums[i],
		)

		res = max(res, dp[i])
	}

	return res
}
```

注意这里代码中的：`res = max(res, dp[i])`，因为 `dp[i]` 表示的是**以 `nums[i]` 结尾**的最大子数组和，而最大子数组不一定在最后一个元素结束，所以最后的答案是：

```go
max(dp[0], dp[1], ..., dp[n-1])
```

所以写成 `res = max(res, dp[i])`。

### 进一步优化

现在再观察：

与上面提到的 `prefix` 数组一样，我们并不是时刻需要每一个`dp[i]`，`dp[i]`其实只依赖 `dp[i-1]`，所以：

```
dp := make([]int, len(nums))
```

`dp[i]` 其实也没必要全部保留在数组中，只保存上一个 dp 即可。

接下来用 `current` 表示当前以 `nums[i]` 结尾的最大子数组和。

于是：

```go
func maxSubArray(nums []int) int {
	current := nums[0]
	res := nums[0]

	for i := 1; i < len(nums); i++ {
		current = max(
			nums[i],
			current+nums[i],
		)

		res = max(res, current)
	}

	return res
}
```

这就是经典的 **Kadane 算法**，时间 O(n)，空间 O(1)。

## 总结

这道题最后可以用很短的代码解决，从暴力方法一步步优化下来，可以看到很多很经典的算法思想。

对于**前缀和**的方法：

- 最开始利用前缀和，将区间求和步骤从 O(n) 优化到 O(1)；
- 接着发现对于固定的右端点，只需要找到左边最小的前缀和，而不需要枚举所有左端点；
- 最后又发现不需要保存完整的前缀和数组，只需要记录当前前缀和与最小前缀和。

最终将时间复杂度优化到 O(n)，空间复杂度优化到 O(1)。

对于**动态规划**的方法，则换了一个角度思考问题：如果子数组必须以 `nums[i]` 结尾，那么最大的子数组和是多少？

于是定义：`dp[i] = 以 nums[i] 结尾的最大子数组和`

得到状态转移方程：$dp[i] = max(nums[i], dp[i-1] + nums[i])$

由于 `dp[i]` 只依赖 `dp[i-1]`，最终又可以将 DP 数组压缩成一个变量，这就是经典的 Kadane 算法。

这两种方法看起来不同，但实际上都有一个共同点：

**当右端点不断向右移动时，只维护计算当前最优答案真正需要的信息，而不是保留或枚举所有历史状态。**

前缀和维护的是：当前前缀和 + 已知最小前缀和

Kadane 算法维护的是：以当前位置结尾的最大子数组和

最终它们都可以做到时间复杂度：O(n)，空间复杂度：O(1)
